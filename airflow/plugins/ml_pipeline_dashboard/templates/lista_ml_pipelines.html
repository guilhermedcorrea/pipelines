Catálogo operacional dos DAGs de Machine Learning. Esta tela foi desenhada para o usuário entender rapidamente quais pipelines existem, qual foi o último status, quais tags estão associadas, quem é o owner e qual execução merece investigação.

Airflow + ML + Observabilidade
Total de pipelines - Quantidade de DAGs classificados como Machine Learning pela API do plugin.
Último status: sucesso - DAGs cuja execução mais recente retornou estado success.
Último status: falha - DAGs cuja execução mais recente retornou estado failed.
Em andamento / fila - DAGs com execução ainda em progresso, em fila ou processamento em curso.

Filtros do catálogo

O filtro atua diretamente sobre a API de listagem do plugin. Ele serve para localizar um DAG específico, analisar apenas um status ou limitar o volume retornado para manter a tela leve.
